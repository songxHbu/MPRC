# MPRC paper experiment scripts

The original file `2d932a83-daec-46d4-ac68-b3e11adf9bb4.py` is copied into this folder **without modification**. All additional experiments dynamically import that file and write results to separate directories.

## Files

- `mprc_experiment_utils.py`: shared loader, checkpoint utilities, ablation subclass, metrics and CSV/JSON writers.
- `run_ablation_study.py`: Panel A representation ablations and Panel B calibration ablations. The full model is trained once; MPRC-Raw and MPRC-Calibrated use the same checkpoint.
- `run_beta_sensitivity.py`: evaluates a checkpoint over multiple beta values and saves CSV plus NDCG/ARP/TAIL plots.
- `run_user_group_analysis.py`: computes each user's average historical popularity and reports Low/Medium/High group results, user gates and item gates.
- `run_item_group_analysis.py`: reports Head/Middle/Tail target-item accuracy and exposure share.
- `run_multi_seed.py`: repeats training for multiple seeds and outputs mean and standard deviation.
- `run_case_study.py`: exports user-level Raw-vs-Calibrated recommendation changes, popularity, gates and residuals.

## Important protocol choices

1. **Representation ablations** (`ID-only`, `w/o Semantic Path`, `w/o Popularity Path`, `w/o Item Graph`) are evaluated with raw inference (`beta=0`).
2. **Calibration ablations** use calibrated inference. By default, all Panel B variants use the beta selected by the complete model, avoiding per-variant beta tuning.
3. `w/o User Gate` replaces the user gate with 1; `w/o Item Gate` replaces the item gate with 1.
4. `Fixed-R` replaces the adaptive user-item gate product with a constant `--fixed_r` (default 0.5).
5. `w/o Popularity Sequence` replaces the history-derived popularity representation with a static user-ID representation.
6. The Head/Middle/Tail boundaries are configurable. The defaults are Tail <= 80th percentile, Middle = 80th--95th percentile, and Head > 95th percentile. Change these values to match the final manuscript protocol.

## Example: train all ablations on Clothing

```bash
python run_ablation_study.py \
  --data_path ./data/Clothing \
  --inter_file clothing.inter \
  --text_feat_file text_feat.npy \
  --image_feat_file image_feat.npy \
  --dataset_name Clothing \
  --output_dir ./paper_results/ablation_clothing \
  --beta_selection tradeoff
```

For your current filenames, replace `clothing.inter` with `Copy of clothing.inter` and feature names as needed.

## Beta sensitivity

Use the full-model checkpoint generated by the ablation script:

```bash
python run_beta_sensitivity.py \
  --checkpoint ./paper_results/ablation_clothing/Clothing_full_seed2024.pt \
  --data_path ./data/Clothing \
  --inter_file clothing.inter \
  --text_feat_file text_feat.npy \
  --image_feat_file image_feat.npy \
  --dataset_name Clothing \
  --beta_candidates 0,0.01,0.02,0.05,0.1,0.2
```

## What these scripts do not reproduce

The scripts cover experiments involving your MPRC model itself: Raw/Calibrated comparison, ablations, beta sensitivity, user/item groups, repeated seeds and case studies. They do not implement external baselines such as LightGCN, LATTICE, BM3, DICE or PPAC. Those methods require their own official implementations and preprocessing protocols for a defensible comparison.

## Run the complete suite for three datasets

Edit `datasets.example.json`, then run:

```bash
python run_paper_suite.py \
  --config datasets.example.json \
  --tasks ablation,beta,user_groups,item_groups,case_study,multi_seed \
  --output_root ./paper_results/suite
```

Each task writes an independent log file. The suite stops immediately when one task fails, so the corresponding log can be inspected without mixing outputs from later experiments.
